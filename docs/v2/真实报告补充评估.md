# 真实报告补充评估：输出前冻结

短合成测试不代表真实报告。为检查复杂句、长报告、多个器官与上下文，增加16条公开真实报告作为开发样本，24条作为新的最终测试。在读取其模型输出前冻结来源、划分和散列，最终测试不用于选模型或修改提示词。

数据来自第一版同一公开BioLaySumm数据集的官方validation，固定revision `6783ab38f9de28c4372799346f51d3927ae7eb9a`。排除第一版train、validation、test全部报告的标准化文本散列，再去重。从20–2400字符且参考非空的报告中按长度分三层：20–399、400–999、1000–2400字符；每层先以固定随机种子37102602打乱，分别取4/6/6条开发、8/8/8条测试。

只按原文长度取样，不看任何模型输出或错误。排除精确文本重复不等于患者独立。不能确定是否与基础模型预训练语料重叠。原始文本与完整输出仅保存在被Git忽略的data或real-data目录，Git只保存散列、汇总和非逐字的错误类型说明，不重新分发数据集。

真实报告没有医生验证的中文金标准，逐例复核仍由项目AI完成。每例检查数值/时间、否定、确定性、位置、变化、建议、遗漏与新增内容，并报告完整解释覆盖率。英语原报告本身可能有矛盾或错误；不得把教师中文当裁判。医疗事实错误与通俗程度分开判断，复杂原句导致保留原文时算未完成解释。

最终版本、模型、推理预算和代码散列在候选锁文件中保存后再运行测试。合成和真实报告分开统计。若真实报告暴露新问题，该轮如实记录，不修改同一版本再反复报分。若确需另起改进版本，则原最终集转为回归数据，并冻结新的独立测试。
