## 不加载模型的复核

在项目根目录，使用现有`.venv-mac`。下面命令只读原结果，把派生文件写入新目录；工具拒绝覆盖已有目标。

```bash
mkdir -p data/v2/reproduction
PYTHONPATH=. .venv-mac/bin/python scripts/summarize_v2.py --outputs results/v2/final_gpu_evidence/outputs.jsonl --review results/v2/final_gpu_evidence/review.json --out data/v2/reproduction/gpu_synthetic_summary.json
PYTHONPATH=. .venv-mac/bin/python scripts/summarize_v2.py --outputs results/v2/real-data/final_gpu_evidence/outputs.jsonl --review results/v2/final_real_reviews/gpu_evidence_review.json --out data/v2/reproduction/gpu_real_summary.json
```

每份复核绑定规范化输出SHA256；ID、行内容或判断不完整时拒绝汇总。它不使用规则通过率推断医学事实。

## 重放冻结的候选筛选

```bash
PYTHONPATH=. .venv-mac/bin/python scripts/recheck_v2_outputs.py --input results/v2/real-data/final_gpu_evidence/outputs.jsonl --reports data/v2/real/holdout.jsonl --original-runtime results/v2/real-data/final_gpu_evidence/runtime.json --out results/v2/real-data/reproduced_gpu_recheck --split real --stage final --candidate-lock examples/v2/candidate_gpu_recheck.lock.json
```

这会核对冻结代码、候选锁、输入次序与散列，并保留原模型运行耗时。新执行的CPU计时不同，因此整个重检行的SHA可能不同；不得将旧复核无检查地套到新行上。只有原文、显示中文、显示状态与词典完全一致，才可记录机械一致性后重新绑定复核散列。没有调用模型也不等于没有原始计算成本。
