# 第二轮：先改善事实，再比较模型

冻结时间由 `examples/v2/holdout_manifest.json` 记录；该文件同时记录测试集 SHA256。此计划在观察任何 v2 新测试输出前保存。第一版的模型、提示词、原始结果和报告不改写。

## 目标与预算

用户授权最多约8小时自主改进，2026-10-16布里斯班06:00起，质量足够时可提前完成。优先选择能够在这台8GB Apple Silicon Mac独立运行的方案，不受课程模型清单限制。学校A100可用，但不能为了使用GPU而重复训练。

原来的20例挑战集现在只作开发和回归。新增48例中英文合成测试（各24例）在观察输出前冻结，不参与训练、提示词修改或模型选择。它们由AI编写、AI分析，没有医生标注，不是临床验证集。事实清单是本次分析的检查要点，不是经过专家裁定的金标准。

## 候选方案与选择

先在旧20例上比较原有微调Qwen2.5-1.5B、Qwen3-4B-Instruct-2507及Qwen3.5-4B的4位MLX版本。后两者使用锁定版本的MLX Community转换，记录原始模型来源、许可证、文件散列、运行时间和内存；不冒称自己训练或官方直接发布的量化版。先试直接中文改写；再比较逐句对应原文、输出前检查、必要时至多一次修订的方案。思考模式关闭，以便比较直接解释和适合本机的响应速度。

模型选择只看开发集：优先减少事实错误，其次保持完整中文解释的覆盖率，再考虑术语可读性、速度和内存。不能以更高的拒绝率代替真实改进。若更强基础模型已明显更好，无需再用同一批合成标签微调；若仍有稳定错误且训练能解决，再启动独立A100实验。所有额外训练数据不得包含本测试或其改写。

最终新测试至少比较：(A)第一版原始微调模型；(B)开发选定的更强模型直接改写；(C)选定模型加逐句证据与校验。若选型后发现本机性能不可接受，保留测量并选择实际可用方案，不事后删除失败实验。查看最终测试后不再修改同一候选版本；发现问题记录为限制或另起版本并使用新测试。

## 校验与输出原则

- 将解释与原文片段对应，保留原始顺序；不把文中的指令当作任务指令。
- 额外术语说明与患者具体发现分开，提供来源链接，不能由词典自动推断患者有病、原因、治疗或预后。
- 检查数值及其顺序、单位、日期、否定、不确定性、左右侧、变化和建议。规则检查是有限模式匹配，不能证明事实正确。必须用刻意错误和正确改写测试其漏报与误报。
- 发现疑点时允许一次修订。仍有疑点的片段保留原文、标记未完成中文解释；不把它计为成功，不向用户展示未通过的候选正文。研发JSON可保存候选用于审计。
- 不静默截断输入，不展示达到生成上限的半段解释。整篇的拒绝、片段回退、空输出都单独记录。

## 预先规定的统计与复核

记录每例原始输出、最终展示内容、原文对应、回退原因、完成情况、耗时和token数。事实复核逐例标注：数值/时间、否定、确定性、位置/左右、变化、建议、遗漏、无依据添加。评审由本项目AI完成，不声称独立盲审。测试量小，只报告观察到的例数，不称医疗准确率。

同时报告有事实错误的报告数、全部关键点保留的报告数、完全提供中文解释的报告数、片段覆盖率、回退数、重要遗漏数。回退引用原文不算完成解释；若最终保留原文，只说明避免展示某一可疑改写，不能算模型答对。固定术语词典覆盖率、句长只能作为可读性代理，不能证明患者理解。

报告配对错误差异及案例，不追求ROUGE提高。原始版本与新模型、整篇与逐句、修订前后分别保留，避免将模型升级和校验作用混为一谈。耗时含推理但模型加载另列，峰值MLX分配内存不等于系统总内存。开发集和最终测试结果分开。

## 提前完成的判断

优先观察最严重的数字/随访时间、肯定否定、左右侧、确定性错误是否减少，且完整中文解释覆盖率没有明显牺牲。如果仍有错误，不能宣布临床可靠；在有用改进充分验证、继续训练收益不明确时也可交付研究版本，并列出具体不足与下一步。
