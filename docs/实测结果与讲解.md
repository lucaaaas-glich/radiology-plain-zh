# 这次实验做出了什么

我们完成了一个“英文或中文影像报告输入，中文解释输出”的研究原型，并在学校的A100上真正训练了一个LoRA适配器。固定测试集上的文字相似度有所提升，但实际输出仍有数字、否定范围和确定性错误。这个项目适合学习模型微调与评估，目前不适合直接给患者作为可靠解释使用。

这是放射科报告通俗化，不是根据影像诊断，也不是把各种处方和医嘱自动改写成用药指导。原课程文件的放射科报告选题是起点；我们为中文目标选择Qwen，作为独立兴趣项目，不提交为第二份课程作业。

## 两个改善和三个失败

以下都是预先编写的合成挑战输入产生的真实输出，没有为展示效果重新生成或挑选随机种子。全部20条对比在 `results/pilot_v1/challenge_review.json`。

**改善：保留“性质未定”。** 输入描述右肺上叶6毫米结节，性质未定，建议与既往影像比较。基线没有写出性质未定；LoRA明确写出“目前不确定其性质”。

**改善：不再混淆积液与积气。** 输入左侧少量胸腔积液、右侧没有积液。基线写“积液（积气）”；LoRA去除了错误的积气括注，保留了左右差异。

**失败：新增错误的算术。** 输入从5毫米变成8毫米、3个月后复查CT。LoRA原样输出：

> 左下肺有一个小结节，现在比之前大了1毫米，从5毫米变成了8毫米。建议三个月后复查CT。

两个原始数字都出现了，但新增的增量是错的。仅检查是否包含5和8不能发现所有问题。

**失败：中文输入也会改错数字。** 输入约7毫米、之前6毫米、6个月后复查。基线保留了两个大小；LoRA写“比之前大了0.5毫米”。训练主要覆盖英文到中文，不能因为基础模型支持中文，就认为中文输入已经充分验证。

**失败：扩大否定范围。** 输入“未见明显实变影”，LoRA写“双肺看起来正常”。原文只否定某类发现，模型却扩大成了整体正常。数字检查器无法发现这种语义变化。

## 真实数据中的五类观察

这五例按原报告的关键词选择，不按哪个模型表现更好来选择。完整原文与输出仅保存在本地 `results/pilot_v1/case-review.json`；Git仓库保留ID及分析。以下是AI辅助的文字核对，没有医生审核。

1. **否定及源文歧义。** 某原文把未见肺动脉充盈缺损与支持肺栓塞的措辞放在同一句。两个模型都没有明确指出冲突；教师参考也有解剖名词误写。这例不应被当作没有争议的标准答案。
2. **不确定性与日期。** 两模型保留了炎症或感染的可能性，但教师和学生对模糊日月格式的理解不同。参考不一定永远正确；单凭文字不一致无法判定哪一个日期解释正确。
3. **随访间隔。** 一份长报告建议6个月后复查，LoRA改成3个月，并遗漏结节大小；基线保留间隔，却误译了其他发现。更高的总分掩盖不了这类改变。
4. **不能排除变成确定。** 一例原文说不能排除某区域病变，LoRA改成仍然存在病理变化。基线在这一点上更忠实。
5. **导管和解剖部位。** LoRA更清楚保留了导管尖端位置及肺门描述，但仍有未解释术语和细节省略，不能认为通俗化已经完成。

## 本地程序额外做了什么

在看到上述数字错误之后，增加了一个独立的数字与单位核对器。它对比原文和生成文本中的毫米、厘米、常见随访时间，可以识别30毫米等于3厘米、半年等于6个月，并提示新增或遗漏的数值。

它**不会改写模型答案**，也没有参与训练、选模或以上原始指标计算。这是试验之后增加的应用层提示，不能作为模型在盲测中通过的能力。数值相同但前后顺序颠倒、否定改变、左右侧错误、复杂范围和其他医学事实，都可能漏检。没有提示也不代表答案正确。

Mac的4位模型正在单独验证。完成后的实测速度、内存和量化输出差异记录在 `results/mac_4bit_v1/`；不要把未完成的本地验证写成通过。

## 用这个项目学会六件事

1. **基线很重要。** 原始Qwen已经会说中文。只有同样输入、提示词和生成设置的前后对比，才能看出微调改变了什么。
2. **LoRA只训练一小部分。** 大约15亿参数的语言能力来自预训练；这次训练约436万参数，使它更适应报告解释风格。
3. **合成标签便宜但会带错。** 教师可以快速生成数千条中文参考，同时也会产生误译和难懂术语。学生可能忠实地学到这些问题。
4. **损失下降是学习信号，不是临床认证。** 模型更会预测参考答案中的词，不代表每一个数值和判断都保真。
5. **测试必须看内容。** 文字指标、事实核对和患者可读性是不同的问题，需要分别评估。
6. **部署是另一段实验。** GPU上跑通之后，还要做权重合并、压缩、下载、校验以及本地实际生成。

如果继续做下一轮，最有价值的方向是人工审核的中文成对数据、数字与否定等细粒度训练样例、独立的中文测试集，以及专业人员的事实与可读性评估。不能在看过这次测试输出之后反复调参，再把同一批报告称作新的盲测。

## 证据与复现

主实验运行源码为 `d081044`，后续版本增加本地界面、复现参数、数值提示和分析。`results/pilot_v1/comparison.json`包含训练历史、固定划分、教师统计和指标；`models.lock.json`记录模型revision；`paired_lexical_analysis.json`记录bootstrap设置。

原配置中的 `max_source_tokens=640` 没有在该版代码中使用。实际约束为报告及英文参考各20到2,400字符、训练完整序列不超过1,152token；没有因完整训练序列过长而剔除样本。这个未使用字段不应被误读成已经执行的640token截断。
