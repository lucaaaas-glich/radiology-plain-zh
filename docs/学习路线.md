# 从一次中文解释，理解整个项目

本页解释设计与代码。实测数字、输出示例与失败分析在实验结束后单独记录，不能把这里的示意文字当作模型结果。

## 1. 输入、输出和边界

输入是一段放射科医生写的报告，输出是一段患者更容易理解的中文。
模型必须同时完成两件事：把语言说简单，把事实保留下来。

例如原文中的 `cannot exclude` 表示“不能排除”。删掉它，会把尚未确定的事情变成确定的事情。
左右侧、大小、前后变化也属于事实，不能为了流畅而省略。

这与“根据 X 光片诊断疾病”是不同的输入任务：本项目只有文字，没有把影像送入网络。
模型也没有得到患者完整病史，因此不应补写治疗方案或推断原文没有的病情。

## 2. 为什么不从零训练

Qwen 的预训练参数已经包含大量通用语言模式，也能理解中文和英文。
本项目只让它适应“依据影像报告生成通俗中文”这一种工作方式。

- 预训练：基础模型此前的大规模学习，不是本项目完成的工作。
- 推理：参数不变，给模型一段报告，让它生成解释。
- 微调：用成对样本计算错误，再更新一小部分参数。

未微调的 Qwen 已经能输出中文，因此必须先把它当成基线。否则，只展示微调后的几个例子，无法知道训练到底是否有帮助。

## 3. 中文训练答案从哪里来

原始 BioLaySumm 数据提供英文专业报告与英文通俗参考。
我们让一个较大的冻结模型同时阅读二者，生成中文通俗参考。
之后，小模型学习“英文报告到中文参考”的映射。

这是一个小规模的教师—学生实验。教师模型的输出是**合成标签**，并不自动等于正确答案。
教师可能误译否定或数字，小模型也可能学到这些错误。教师与学生又属于同一模型家族，评估时的偏差需要说明。

代码里的 `teacher_accepted` 只检查语言比例、长度与是否正常结束；它不表示“经过医学审核”。

## 4. LoRA 具体更新什么

普通全参数微调会更新大量原始参数。LoRA 冻结原始权重，为选定的注意力投影加入两个较小的矩阵。

对于原来的权重 W，实际计算使用：

`W + (alpha / r) × B × A`

本实验将 `r` 设为16，`alpha` 设为32，应用到注意力的 q/k/v/o 投影。
训练主要修改 A 和 B。原始模型仍然需要参加前向计算，所以“可训练参数少”并不表示计算量和显存都能按同样比例减少。

训练结束保存的是 adapter。使用时，需要基础模型加上这个 adapter；本地压缩版会先把两者合并，再做4-bit量化。

## 5. 为什么只计算答案部分的损失

训练序列包括系统要求、报告和目标答案。报告是输入，不是我们希望模型在这个任务中学习生成的结果。

因此，我们把系统要求、报告和补齐位置对应的标签设为 `-100`，让损失函数忽略它们。
真正参与训练损失的是中文答案及其结束标记。

这不表示模型看不到报告：报告仍然进入注意力计算，只是不被当作需要预测的训练答案。

## 6. 训练集、开发集与测试集

- 训练集用于更新 adapter。
- 开发集用于选择训练轮次，本实验根据答案 token 的交叉熵选择 checkpoint。
- 最终测试集用于比较已经选定的模型。看到结果后不能反复调整模型，再把同一集合称为新的盲测。

本项目先对报告文本去重，再选择子集。它可以阻止完全相同的报告跨集合，不能证明没有同一患者的不同报告。
缺少患者标识时，这项局限必须保留。

## 7. ROUGE 和 chrF 能说明什么

它们衡量输出与中文参考在词、字符或顺序上有多接近。
中文需要适当分词；英文默认的 ROUGE tokenizer 会过滤掉中文字符，可能给出无意义的零分。

“有气胸”和“没有气胸”只差少量文字，医学含义却相反。因此，分数上升也可能与关键错误并存。
本项目的参考还是合成的，更准确的解释是“更像教师写的答案”，而不是“医疗准确率提高了多少”。

## 8. 读一个真实结果时，按这个顺序看

1. 阅读原始报告，圈出否定、不确定性、左右侧、数字与建议。
2. 看基线输出，有没有增加、遗漏或改变这些内容。
3. 看微调输出，用相同标准检查。
4. 分开记录事实错误、难懂术语、句子冗余以及表达改善。
5. 再看文本指标，解释它与病例观察一致或不一致的地方。

如果微调分数升高但出现新的重要遗漏，应当把两件事一起报告。这个发现本身就是研究结果。

## 9. 为什么本地版本还需要再验证

A100 上的模型主要使用 BF16，Mac 本地版本会把合并后的参数压缩成4-bit。
量化节省存储与内存，但参数数值发生变化，输出可能改变。
因此，本地模型必须重新生成同一组小样例，记录本地速度、内存与输出差异。

## 10. 可以用来检查自己是否理解的五个问题

1. 基线已经能说中文，为什么还要微调？如何证明微调有价值？
2. 教师输出流畅，为什么仍然不能把它当成医生写的标准答案？
3. 把报告标签设为 -100 后，模型还会利用报告吗？
4. ROUGE 上升但把“不能排除”删了，应该怎样描述结果？
5. A100 每秒生成很多 token，为什么不能直接推断 Mac 上的速度？
