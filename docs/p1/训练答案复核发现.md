# 训练答案复核发现

这轮先检查“教模型的答案有没有问题”，再比较模型。这里所有事实审查都来自本项目的 AI，人工和临床专家复核仍为 **0**。原始答案和旧实验均保留。

新留出的30条真实训练答案按来源各取10条，并覆盖少见的长度和风险类型。逐条先读源文、再对照答案，观察到15条有明确源文不一致、14条有信息遗漏、15条有无法判定的内容；三类可以重叠。这是有意分层的小样本，不能推算整个数据集有一半错误，也不是影像诊断的真伪判定。

最值得注意的结果是：新规则没有把上述15条明确错误中的任何一条判为可自动排除。它给其中8条提示“需要复核”，另外7条没有支持的问题信号。所以“没报警”仍不等于答案正确。

## 规则变保守后的收益与代价

在另外30组合成对照中，新规则没有把正确对照判成可自动排除；旧规则会对其中4条报警。但30个预先写入的错误中，新规则只明确识别6个，另9个进入复核提示，15个没有信号。两版的报警级别和用途不同，不能用这几个数拼成统一“准确率”。

完整4066条格式合格的训练答案中，新规则标出22条明确问题、884条需要复核、3160条未发现支持的问题。对22条全部逐条检查后，只有13条的排除依据获得项目AI支持，4条是误报，5条无法明确判定。

误报包括：原文已经说明某种感染表现稳定，规则却以为答案新加了感染；原文已经说管子放置合适，规则却认为中文“位置正确”是新增结论；不同检查各自的日期被错误配成一组。它们说明，即使规则给了证据片段，也可能把关系配错。

## 正式比较实际改动多大

保留原规则和初始选择结果后，在任何正式模型预测之前声明了修订：只有“规则明确报警”且“逐条复核支持”的样本才允许排除。误报、混合结论、无法判定以及仅提示复核的样本都保留。原答案没有重写。

两组各1024条，最终共享1020条，只替换4条。替换幅度不足0.4%，这是很弱的干预；不能预期它让整个模型显著变好。相同筛选和打乱算法还使125条共同样本的排列位置移动，因此比较的是完整选样政策，不是固定所有批次位置后只换四条答案的实验。

这一修订是在看过规则验证结果后提出的，所以新组合流程没有独立的筛查验证。接下来40份从未用于本项目开发的新报告用于探索性模型对比，不用于继续调整规则或挑模型。训练模型只按共同开发集的答案损失选择轮次。

真正推进的是：排除了已确认的几条问题、挡住了已发现的规则误删，并把“判断不了”诚实地保留下来。是否改善最终中文，需要看三组实际输出；这一步本身尚不能证明模型能力提升。
