# 开发过程与边界

这一轮只用上轮已经看过的报告开发。40 份新长报告及评价方案先冻结，随后才选择具体实现。最终新测试不能再用于调整代码。

## 实际发现的问题

初始 27B 事实清单流程在 8 份旧真实报告上仍出现 4 份明确错误，只有 1 份完整且未发现错误。数字是本项目 AI 逐例审阅结果，不是临床准确率。错误包括胸片 PA 投照方向反转、猜测未知单字母代表性别、遗漏部位限定、胸椎定位变成泛指下背部。大量原文回退还隐藏着另一种失败：病人没有得到完整解释。

4B 本机候选的两个旧例也未得到完整忠实解释。它一度把呼吸衰竭简化为呼吸困难，还会产生重复 JSON 字段。只修格式和提示词不能证明小模型已经具备长报告能力，因此不把它选作本轮主模型。

## 当前候选的处理

- 保留原文精确位置、标题和编号，按小组读取上下文。清单的每条依据必须逐字来自对应原文；临床词不能因为提取清单而被静默丢弃。
- 清单只提取一次，分别验证各片段。一个片段的格式失败不丢弃其他片段的有效清单。重复 JSON 字段直接判为无效，避免后一个位置覆盖前一个位置。
- 无效清单不传给改写器，也不展示为依据；该片段仍可直接对照原文生成，再经过同样的双向核对与数字检查。若核对员否定清单，则丢弃清单，重新从原文生成并重新核对，不能直接放行旧译文。
- 明确记录“有清单生成”和“没有有效清单而从原文生成”的数量。有效清单也可能理解错误，绝不称它为标准答案。
- 核对员只检查对应片段，不要求它重复别处的事实；标题、同义表达不应被当作临床遗漏。最多两次生成尝试，仍失败则明确保留原文。
- 加入窄范围投照方向检查，以及带出处的呼吸衰竭、PA/AP 词义。规则只是捕捉已知错误模式，不能包办医学语义。

## 运行时间实验

最初 A100 上约每秒 7 个输出 token，多次抽取和核对很慢。我们在独立 V3 目录安装固定版本的官方 FLA 运算组件，没有改动旧环境、旧模型或其他作业。只有两个 Gated Delta Rule 运算在进程内切换为加速实现；两种最终方案必须使用相同运行方式。

GPU 数值小测试的最大相对均方根偏差约 0.00434；这只检查运算实现，不证明医学效果等价。两条旧短例的新旧实现输出相同，但其中一次有首次编译开销。第二例推理从 2.519 秒变为 2.236 秒，改善有限；不能宣传为大幅加速。实际长文时间仍以最终逐例记录为准。

## 方法来源

逐条事实核对受到 [FActScore 论文](https://aclanthology.org/2023.emnlp-main.741/)的启发，但原论文的传记评价并不证明本项目医学改写有效。[FLA 官方实现](https://github.com/fla-org/flash-linear-attention)只用于运行优化。[NHLBI 呼吸衰竭说明](https://www.nhlbi.nih.gov/health/respiratory-failure)和 [英国政府放射诊断参考资料](https://www.gov.uk/government/publications/diagnostic-radiology-national-diagnostic-reference-levels-ndrls/ndrl)分别支持相关词义与投照名称。最终是否有效仍取决于新报告中的真实错误、完整覆盖和阅读难度。

## 第二次审阅发现的规则误导

Dev4旧例中，粗糙词汇提示会将“纵隔（两肺之间）”视为擅自添加双侧位置，并把COVID-19的19当成必须复制的患者数值，进而误导文本核对员。Dev5保留完整规则诊断记录，但只向核对员传递数值、日期、投照方向的强约束提示。其他语义由原文与中文直接对照。对不存在清单的“清单遗漏”投诉单独记为不适用；真正的中文意义变化、遗漏投诉仍阻止放行。该调整先在旧真实报告2、9、13、14上验证，不能以新测试选择。

曾申请第二张空闲A100以并行执行对照，但学校返回QOSMaxJobsPerUserLimit。仅撤销了本项目未开始的作业666998，没有修改配额或其他作业。仍使用作业666860。静态缓存/编译方案仅作为有超时上限的旧例运行实验排队，是否采用须有实际证据；不能把未执行代码当成加速成果。

## 运行探针结果及术语补充

静态缓存/编译配置探针已在两条旧短例执行，输出与原配置一致，但库明确提示编译条件不满足而跳过编译。暖运行分别为2.648和2.764秒，原配置为2.607和2.688秒，没有提速。已恢复原生成配置，不采用该方案，也不宣称完成了编译加速。相关原理来自[Transformers官方运行优化说明](https://github.com/huggingface/transformers/blob/main/docs/source/en/optimization_overview.md)，实际支持情况以本次日志为准。

Dev5本机4B的两份旧报告仍无完整忠实输出，其中一份出现锁骨下静脉定位缺字和胸椎定位错误；不能把段落覆盖增加宣传为质量提高。Dev6针对已知词义混淆补充窄范围词典：subclavian vein对应锁骨下静脉，dorsal vertebrae是胸椎的旧称，不等于随意泛指下背部骨骼。来源为[英国重症医学专业机构的导管指南](https://www.ficm.ac.uk/sites/ficm/files/documents/2024-08/New2ICU_Central_venous_catheter_guide.pdf)及[加拿大政府术语库](https://www.btb.termiumplus.gc.ca/tpv2alpha/alpha-eng.html?i=&index=enr&lang=eng&srchtxt=VERTEBRAE+THORACICAE)。dorsal用于其他组织时不触发胸椎释义。V2词典未修改。

纵隔位于两肺之间的词义由[ACR/RSNA词汇说明](https://www.radiologyinfo.org/glossary?id=ezMxMTkyNTNCLUQ1NTUtNDhFMC04QUNELUU0MzQwRkRFNUYwRn0%3D&modal=1)支持，说明该括注本身不等于新增双侧病变；这正是去除粗糙词汇提示的动机。
